# Data

## Main analysis workbook
`Texas_Tax_Revenue.xlsx` is the original class source workbook retained for the project. The assignment identifies the `Sales Tax` worksheet as the monthly sales-tax series used for the forecasting analysis.

## Reference workbooks
`reference/all_funds_historical.xlsx` and `reference/general_fund_historical.xlsx` were retained with the project materials. The submitted Group 17 R code does not directly read these files, so they are included as supporting historical-revenue references rather than model inputs.

## Missing external VAR inputs
The submitted code references two additional workbooks that were not retained:
- `TXNA.xlsx` - Texas total nonfarm employment
- `CPIAUCSL.xlsx` - U.S. CPI for All Urban Consumers

Until those original inputs are restored, the VAR portion should be described as documented rather than fully reproducible.
